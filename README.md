# Projeto-Boletos-Clovis
Um sistema para controle de Boletos para o Colégio Clovis Bevilacqua.
Ele será uma aplicação web que ajudará tanto o Colégio como os responsáveis financeiros dos alunos a entender e pagar boletos e pendências, essa aplicação vai ter integração com o SAE8.
Por meio desse sistema o responsável financeiro terá acesso ao boleto pendente e as formas de pagamento com tabela relacional de preço por forma de pagamento, e o sistema também vai disparar algum tipo de notificação ao responsável.
